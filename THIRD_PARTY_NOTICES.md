# External reference materials

Original ena_gffprep software is MIT-licensed. External reference data and
executables are acquired separately by users and remain subject to upstream
terms. This notice does not grant rights to redistribute those materials.

- Sequence Ontology, release 2026-08-07: https://purl.obolibrary.org/obo/so.obo
  (https://github.com/The-Sequence-Ontology/SO-Ontologies). Local index retains
  selected identifiers and relationships; upstream licence discrepancy remains
  unresolved. Citation: Eilbeck et al., Genome Biology 6:R44 (2005),
  https://doi.org/10.1186/gb-2005-6-5-r44.
- ENA gff3tools 5.5.1, acquired through a user-supplied Webin CLI JAR:
  https://github.com/enasequence/gff3tools. Local index extracts feature names
  and accessions from the embedded mapping. No JAR or mapping is distributed.
- INSDC Dbxref registry: https://www.insdc.org/submitting-standards/dbxref-qualifier-vocabulary/.
  Users supply a local tag list; its checksum is recorded in the local index.
- INSDC specifications: https://github.com/INSDC-Repo/INSDC.
  Referenced as standards; supplied documents are not redistributed.

Institutional review is recommended before public release. This is not a legal
determination of the upstream licences.
